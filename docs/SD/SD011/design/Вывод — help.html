t1ctl  1.4.0
USAGE
  t1ctl [command]
COMMANDS
  status     print status (default)
  start      start demo
  restart    restart demo
  stock      restore stock autostart
  viewer     Foxglove bridge lifecycle
  mode       set control mode
VIEWER
  viewer status     check bridge and print Mac connection
  viewer start      start read-only bridge
  viewer stop       stop bridge without stopping demo
MODE
  mode forbid       hold motion (Forbidden)
  mode allow        release hold, return to follow
  mode manual       select operator pad
STATUS
  demo              active          mentorpi-t1.service is running
                    inactive        mentorpi-t1.service is down
                    failed          start or restart failed
  stock             inactive        start_node.service is off
                    active          start_node.service is on
  chassis           active          /vehicle/status echo succeeded
                    inactive        container down or no /vehicle/status
  mode              follow          person follow is selected
                    manual          operator pad is selected
                    forbidden       motion held; chassis zeros
  reason            operator        host command t1ctl mode forbid
                    (topic)         critical contour signal missing
  remote controller active          pad receiver has a link
                    inactive        no pad link
  lidar             active          /scan echo and lidar_frame TF ready
                    degraded        demo up but scan or TF missing
                    inactive        container down or probe skipped
  camera            active          color, depth, depth_camera_link TF ready
                    degraded        demo up but color, depth, or TF missing
                    inactive        container down or probe skipped
  imu               active          /imu, /imu_odom, and imu_link TF ready
                    degraded        demo up but IMU, odom, or TF missing
                    inactive        container down or probe skipped
  odometry          active          /odom_raw and odom TF ready
                    degraded        demo up but /odom_raw or TF missing
                    inactive        container down or probe skipped
  platform model    active          /robot_description and model TF ready
                    degraded        demo up but description or TF missing
                    inactive        container down or probe skipped
  version           1.4.0           t1ctl package version
FLAGS
  -h, --help     this help    -V, --version  print version

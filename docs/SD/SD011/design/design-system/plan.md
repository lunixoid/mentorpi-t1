# Design plan: t1ctl (живая ДС)

## Предмет

`t1ctl` на хосте Pi: статус контура и единственный write-путь оператора, включая режим движения. Аудитория — человек в SSH у стенда, не CI и не TUI. Главный вопрос первого взгляда на status: **можно ли ехать, и если нет — почему**.

## Режим

CLI: команда → вывод. Не TUI.

## Сетка

80×24, ячейка 12×24, кегль 20px, chrome 36px, artboard 960×612. Справка `--help` — 80×52 / 960×1284: словарь STATUS уже длиннее классических 24 рядов; макет показывает полный дамп, в терминале он скроллится.

## Цветовая модель

ANSI-16 по ролям, в макете truecolor. NO_COLOR: те же глифы и выравнивание, без цвета.

## Палитра → роли

Не матрица и не шаблон скилла (камень + teal + IBM Plex). Цех / гусеница / окись — палитра «Трак T1» из онбординга SD002, без смены hue.

| Hex | Роль |
|-----|------|
| `#E9E1CC` | bg холст |
| `#241E16` | fg резина |
| `#6A6356` | muted / dim |
| `#B33A1A` | accent = warn, prompt |
| `#3F4F20` | ok олива / `active` |
| `#8C1E2E` | err / `failed` / `forbidden` / `degraded` |

info = fg. Семь оттенков не плодим.

## Типографика

**Red Hat Mono** 400 / 700. Не JetBrains, не IBM Plex. Лигатуры выкл. Dim = muted.

## Box

ASCII. На статусе рамок нет. Переход режима: `->`.

## Промпт

`$ ` цветом accent. Не `❯`.

## Signature

Не линейки `=---`. Не баннер на всю ширину (это был бы дефолтный «алерт»). Одно место: `forbidden` bold err + ключ `reason` + next-step `t1ctl mode allow`. Смысл без цвета: слово `forbidden` vs `follow`/`manual`.

## Антипаттерны

Чёрный+зелёный, macOS dots, радуга help, emoji, выдуманные секунды, `mode follow` когда граф молчит, русский в CLI.

## Handoff

Clap / CLI11. stdout — данные и next-step; stderr — `error:`; exit 0 / 1.

## Самокритика

«Тёмный терминал + зелёный + rounded + JetBrains» отвергнут ещё на онбординге. Светлый холст близок к solarized-light admin: отличие в оливковом `active`, словаре systemd+режим, oxide prompt. Для запрета движения не добавлен второй акцент и не нарисован dashboard: это всё ещё kv-утилита, а не TUI охраны. Banнер `MOTION HELD` был бы громче, но ломал бы sparse-голос `Started.` / `demo failed` и дублировал бы слово `forbidden`.

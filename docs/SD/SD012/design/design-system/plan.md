# Design plan: t1ctl calib (SD012)

## Предмет

`t1ctl` на хосте Pi. Оператор в SSH у стенда сводит позы лидара, depth-камеры и IMU. Не CI, не TUI, не правка URDF. Главный вопрос первого взгляда: **насколько сенсоры сейчас разъехались, и откуда взяты позы**.

## Режим

CLI: команда → поток kv. Этап удерживает терминал, пока идут данные, затем печатает предложение и выходит. Accept / reject / save — отдельные вызовы, не `y/N` и не полноэкранный мастер.

## Сетка

80×24, ячейка 12×24, кегль 20px, chrome 36px, artboard 960×612. Справка `--help`: 80×67 / 960×1644 (секция CALIB + ключ `calibration` в STATUS).

## Цветовая модель / палитра / тип / box / промпт

Как живая ДС «Трак T1» (SD011): холст `#E9E1CC`, окись prompt, олива `active`, ascii, `$ `, Red Hat Mono. Новых hue нет.

## Signature

Два места, оба уже в языке `t1ctl`:

1. Ключ `residual` — невязка камера↔лидар в метрах и градусах. Это «можно ли проецировать человека в скан», без порога «ок / не ок».
2. `source unused` — **bold err**, сразу `reason` (файл есть, позы заводские). Как `forbidden` + `reason`, без баннера `CALIBRATION INVALID`.

Поправка этапа: стрелка `->` (уже переход режима). Только изменившиеся оси, единицы `m` / `deg`. Грубый разворот осей — ключ `cause` со значением `axis swap`, не отдельный цвет.

## Команды

`t1ctl calib` = `t1ctl calib status`. Подкоманды: `floor`, `corner`, `drive`, `lidar`, `accept`, `reject`, `save`, `abort`.

В `t1ctl status` — один ключ `calibration`: `factory` | `file` | `unused`. Черновик процедуры на этот ключ не попадает (контур ещё на старых позах). `reason` в общем статусе не занимаем — он у `mode forbidden`.

## Антипаттерны (кроме ДС)

Прогресс-бар, спиннер, TUI-мастер, `? Keep (y/N)`, оптический RPY камеры (−90/−90), радианы, выдуманный порог «calibrated», команда движения шасси, путь файла калибровки (это SA).

## Handoff

Clap / CLI11, `t1ctl` 1.4.1 (patch: новая команда). stdout: kv, next-step, подтверждения. stderr: `error:`. exit 0 help/status/успех write; 1 отказ этапа и ошибка save.

## Самокритика

Дефолт на «калибровку» — мастер с баром и зелёным DONE. Здесь процедура из BA, а голос — sparse kv. `corner` вместо `align`/`match`: оператор ставит робота к углу квартиры, не запускает ICP. Числа в макете — заводские позы T1 (lidar yaw 180°, камера 0.10/0.177), не lorem; остаточные невязки — пример вывода, не SLA.

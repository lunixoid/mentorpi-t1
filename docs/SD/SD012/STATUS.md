- Первый заход BA (отклонён пользователем): ручная интерактивная подгонка шагами по картинке во вьювере. Причины отказа: трудоёмко для 6 величин × 3 сенсора и «на глаз напротив стены ничего не откалибровать».
- Утверждённый метод: автоматический съём по наблюдаемым признакам — плоскость пола (наклон и высота камеры), вектор тяжести (наклон IMU), сведение облака точек со сканом на угле комнаты (камера↔лидар), движение (разворот лидара к базе). Оператор принимает или отклоняет результат этапа.
- Опора в этапе движения — скан-матчинг лидара, а не колёсная одометрия: у платформы неравномерность гусениц (натяжение, диаметры), её ошибка не должна переноситься в калибровку сенсоров. Движение выполняет пользователь пультом.
- Ненаблюдаемые величины (высота, крен, тангаж двумерного лидара) — ручной замер по отдельному документу-инструкции в репозитории со схемой точек замера, ввод числами.

- QA T4 (провал): этап `floor` на стенде даёт недостоверную высоту/наклон камеры — «то задирает вверх, то сквозь пол». Причина: Aurora 930 (структурный свет, 640×400, FOV 74°×51°) видит пол лишь полосой 0.42–1.21 м, ~1300 точек на кадр (4.5% живых точек облака); доминирующая плоскость облака — стена (~8400 точек), а RANSAC текущей реализации требует ≥35% инлайеров и берёт доминирующую плоскость.
- Виток после QA: переработка требований только для пары лидар + depth-камера по методу двух ортогональных плоскостей (Choi et al., T-RO 2016; адаптация — depth даёт плоскости напрямую, ближайшие открытые источники: Fernández-Moral IJRR 2015, Gomez-Ojeda ICRA 2015, Briales IROS 2015). IMU/drive/ручной ввод лидара не меняются.
- Решения пользователя на витке: этапы `floor` и `corner` объединяются в один этап по углу комнаты (пол + две стены под 90°); расчёт IMU остаётся в этом же этапе; одна постановка робота с явным отказом при плохой сцене; оператор обеспечивает строго прямой угол.
- Камера будет физически наклонена вверх (pitch, высота монтажа прежняя) ради обзора корпуса человека. Прикидка по FOV 51° и высоте 0.177 м: при +10° полоса пола сжимается до ~0.65–1.2 м, при +15° — до ~0.95–1.2 м, от ~17° пол уходит из кадра. Решение пользователя: при невидимом поле высота камеры вводится ручным замером как `measured`, остальные пять величин этап считает по стенам; вертикаль и наклон камеры от пола не зависят (восстанавливаются из пары стен).

# SD005. Визуализация данных сенсоров для отладки

## Проблема
1. Для отладки платформы нужно смотреть данные сенсоров и базовые пространственные состояния ROS 2, но предложенный вендором доступ через VNC неудобен для регулярной разработки.
2. Обход сейчас сводится к использованию VNC или разрозненных ROS 2-команд, из-за чего разработчик не получает одного удобного read-only инструмента визуализации, похожего по возможностям на rviz.

## Решение
У платформы появляется отдельный read-only инструмент визуализации, совместимый с ROS 2 и удобный для удалённой разработки без VNC. Разработчик открывает визуальное представление состояния робота на своей рабочей машине, в первом объёме видит TF и одометрию, а дальше может самостоятельно расширять набор отображаемых данных по мере необходимости.

## Сценарии

### Позитивный
1. Разработчик отлаживает платформу и хочет визуально проверить пространственное состояние робота без подключения по VNC.
2. Разработчик открывает инструмент визуализации
   1. Система подключается к ROS 2-данным платформы и показывает доступные визуальные представления
3. Разработчик включает отображение TF и одометрии
   1. Видит положение, ориентацию и связанность кадров в удобном графическом виде
4. Если для отладки позже понадобятся дополнительные данные
   1. Разработчик может расширить конфигурацию или состав отображаемых источников без переделки базового сценария просмотра

### Негативный №1
1. Пункты позитивного сценария №1-2
2. На платформе нет нужных ROS 2-данных или они не публикуются
   1. Инструмент не показывает несуществующие данные и не подменяет их вымышленным состоянием

## Функциональные требования
- Должна быть возможность визуально просматривать ROS 2-данные платформы без использования VNC
- Должна быть возможность просматривать TF платформы
- Должна быть возможность просматривать одометрию платформы
- Инструмент должен быть совместим с ROS 2
- Инструмент должен быть пригоден для удалённой разработки с рабочей машины разработчика
- Должна быть возможность самостоятельно расширять набор визуализируемых данных сверх базового объёма TF и одометрии
- Инструмент должен быть read-only и не должен использоваться для управления движением платформы

## Нефункциональные требования
- Решение предназначено для отладки и разработки, а не для продуктового операторского интерфейса
- По характеру работы инструмент должен быть близок к rviz
- В первом объёме обязательны только TF и одометрия; остальные отображения не фиксируются
- Решение не должно требовать VNC как основного способа работы

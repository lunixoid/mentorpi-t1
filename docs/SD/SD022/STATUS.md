- Диагностика — сверка **трёх** потоков на одной сцене: скан лидара ↔ облако глубины ↔ кадр камеры. Расхождение «скан/облако» указывает на конвенцию облака, «облако/кадр» — на сопоставление пикселя с точкой в перцепшне.
- Сверка идёт **выше детекций**, по сырым потокам: ноутбучный YOLO (`host/mac_person_detect` → `/perception/detections_2d`) — последнее звено цепочки и сам подозреваемый, измерительным прибором быть не может.
- Проверку стороны оператор запускает **командой с хоста** (как этапы `t1ctl calib`), считает по живым потокам, вердикт печатается сразу, в калибровку ничего не пишется. Этой же командой закрываются и метод A (диагностика слоя), и метод B (быстрая проверка) — это одно действие.
- Облако Aurora `640×400` ≈ 4 МБ/кадр → в бэг пишем отрезок в несколько секунд; офлайн-разбор бэга — запасной путь, не основной.

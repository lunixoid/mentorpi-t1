# Design plan: t1ctl

## Предмет

Консольная утилита оператора MentorPi T1 по SSH (Raspberry Pi / контейнер образа). Показывает, жив ли **наш** контур после питания; поднимает и перезапускает его; одной командой возвращает исходный автозапуск Hiwonder. Пока нет фичей следования — робот стоит. Штатные «игры» сами не стартуют. Если контур не поднялся — стоит до ручного вмешательства, сам на Hiwonder не откатывается.

Аудитория: человек в SSH, не CI и не полноэкранный TUI.

Имя команды: **`t1ctl`**. Коротко, предметно (модель T1 + control). Отброшены: `cli`/`app`/`foo`; `mentorctl` — длинно и про бренд шире T1; `contour` — generic; `t1` — путается с моделью.

Копирайт CLI: **English**. Ключи статуса lowercase (`demo`, `stock`, `version`); значения — systemd (`active`, `inactive`, `failed`). В статусе нет дорожной карты фичей и нет chassis. Полное описание статуса живёт в `--help`.

Глагол возврата: **`stock`** — исходный образ/автозапуск, как stock firmware. Не `vendor` (про поставщика, не про состояние), не `revert` (git).

## Режим

CLI: команда → вывод. Не TUI.

## Сетка

80×24, ячейка 12×24, кегль 20px, chrome 36px (подпись кадра + сетка, не окно macOS). Artboard 960×612.

Зачем 80, не 100: оператор на Pi по SSH; статус и help должны читаться в классической ширине.

## Цветовая модель

ANSI-16 по ролям, в макете truecolor. NO_COLOR: те же глифы и выравнивание, без цвета (см. AGENTS.md). Отдельный кадр не нужен.

## Палитра (6 hex) → роли

Цех / гусеница / окись, не «матрица».

| Hex | Роль | Заземление |
|-----|------|------------|
| `#E9E1CC` | bg | холст, бумажный журнал у гусеницы |
| `#241E16` | fg | резина трака |
| `#6A6356` | muted / dim | пыль, вторичный текст |
| `#B33A1A` | accent, warn | окись на траках; питание/осторожность одним цветом |
| `#3F4F20` | ok | оливковая краска шасси — контур жив |
| `#8C1E2E` | err | оксид, не неон |

info = fg (без седьмого оттенка). border/chrome — производные холста, не ANSI.

## Типографика

Один mono: **Red Hat Mono** 400 / 700. Не JetBrains, Fira, Menlo, SF Mono, не шаблонный IBM Plex. Linux/ops, кириллица, индустриально под стенд. Лигатуры выключены. Dim = muted, не меньший кегль.

## Box-drawing

ASCII: `- | +`. Не rounded, не heavy, не nerd-font. SSH на Pi: штампованная шильда, не псевдо-GUI.

## Промпт

`$ ` цветом accent. Классика SSH. Айдентика не в стрелке `❯`.

## Signature (один)

Нет. Не печатать `=---` × 20.

## Антипаттерны

- Чёрный + кислотно-зелёный, scanlines
- Три точки «окна macOS» как айдентика
- Каждый флаг/ключ своим цветом
- Nerd-font, emoji, спиннеры из картинок
- Выдуманные SLA / секунды старта
- GUI-кнопки внутри `.term`

## Handoff

Clap (C++). stdout — статус и подтверждения; stderr — блок `error:`; exit 0 / 1. `--help` → 0.

## Самокритика

План «тёмный терминал + зелёный + rounded unicode + JetBrains» я бы выдал на любой CLI — отвергнут.

Светлый холст близок к solarized-light admin: отличие в **оливковом `active`**, словаре (`demo` / `stock` / systemd) и prompt accent. Линейки `=---` в выводе нет.
